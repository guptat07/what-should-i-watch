This product uses the TMDB API but is not endorsed or certified by TMDB.

This website uses the Google Gemini API to parse user input and return a structured set of information that can be used to query the TMDB API. No information other than what you type into the search field is collected or processed by the site.

Due to the APIs used, the website may make mistakes. This is because the site uses the discover movies endpoint on TMDB, which has no parameter for terms that are more useful when searching by title. Gemini must classify these terms as keywords. Since Gemini provides non-deterministic output, there is no way to tell if it will provide the phrase as a keyword or break down the associations the term has. TMDB is also a highly opinionated platform (e.g., they still list Warriors of the Wind as the primary title of Nausicaä of the Valley of the Wind).
For example, searching for "James Bond" will return films that are in the 007 series as well as other films (generally spy films). With "James Bond," this tends to work out; the films do not have the main character's name in their title, so TMDB often lists it as a keyword in their entries. If you see results from series like Mission: Impossible, it most likely (but not certainly) means that keywords like "spy," "espionage," etc. have been added by Gemini.
Searching for "Lupin III" may return no results. This is because the titles of the films in that series usually contain the main character's name, so TMDB does not include it as a keyword. It also means that Gemini tends not to break down "Lupin III" into associated keywords like "thief."

The point of—and therefore, the best way to use—this tool is as a way to capture your mood when you have an idea of what you want to watch, but aren't totally sure what movies match those vibes; it's best as a way to avoid doomscrolling on a streaming service for two hours before realizing that it's too late to watch anything now.
For that reason, I don't recommend using it for terms like "James Bond" or "Lupin III" in the first place. If you know that you want to watch Star Wars, you can easily find a list of the films in that series online and select one.
